
# Example 2 — Priming, and the first orientation question

Follows on from **Example 1** (getting oriented without AI). This example shows
what happens once you bring an AI assistant in: priming it first, then asking
the first orientation question from the guide, then checking the answer
against the real code.

**Codebase used:** the Ecotropolis fork https://github.com/ValkoM28/Ecotropolis

**Files in this folder:**

- `01-priming.md` — the priming prompt and why it's shaped the way it is
- `02-prompt-response.md` — the first orientation question and the tool's raw answer
- `03-verification.md` — checking three of the answer's claims against the real files

**Guide section:** Step 1, LLM-supported understanding

**After going through the example, feel free to experiment with prompts yourself.**

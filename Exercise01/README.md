## Exercise 1: Predict, then ask

**Files:** `ProgramEx21Nov.cs`, `Program2Ex21Nov.cs`, `Progarm3Ex21Nov.cs` (one small program each)

1. Read `Program2Ex21Nov.cs` (the ranking program). Without running it, write down exactly what it prints.
2. Ask an AI what it prints and why. Compare with your prediction.
3. In the same file, change `hasMicrophone` to `true` and change `playerRank` and `playerPing` to other values. Predict the new output *before* you run it. Then run it.
4. Open `ProgramEx21Nov.cs`. It contains **three** blocks that each choose a light colour. Ask the AI: *"Do these three blocks behave the same for every possible battery level?"* Write down its answer.
5. Test its answer yourself. Try at least these values: `100`, `80`, `0`, `-5`. What happens in each block?

**Turn in:** your notes block, plus a small table of battery level against result for each of the three blocks.

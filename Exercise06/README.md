## Exercise 6: The menu versus the code

**Files:** the whole `Chapter5/` folder

1. Read the menu text in `Main`. Write down what each menu option should do.
2. Ask the AI to build a table with these columns: *menu text, key the user types, method that runs, does that method actually do something?* Ask it to give the line for each row.
3. Verify every row by reading the code **and** by running the program and pressing each key.
4. Answer, first by predicting, then by testing: How does a user leave the program? What happens if the user adds a mission with an empty name? What happens if the same mission is launched twice?
5. Compare the AI's table with what you saw when you ran it. Where did they differ?

**Turn in:** your verified table, a list of every difference between the AI's table and the real behaviour, and your notes block.
